# FIXER'S CUT — 十二夜のヨミハマ

自分では撃たないフィクサーとして、仲間を集め、義体を組み、引き際を決めるブラウザーゲームです。3幕・12夜の道を進み、ハシバの残したブラックボックスを開きます。死んだランナーと装備は次のランへ戻らず、信用・慰霊碑・物語の記録が街に残ります。

企画原本は [Fixer's Cut ローグライク版 企画書](../roguelike-plan.pdf)（2026-11-02、26ページ）。指定リポジトリが空で旧キャンペーン版を取得できなかったため、判定エンジン・画面・文章・データを新規制作しています。仕様の補完判断と未確認事項は [設計上の判断](docs/design-decisions.md)、全体の照合項目は [企画書要件](docs/requirements.md) を参照してください。

## 起動

Node.js が必要です。対応版は `package.json` の `engines` を参照してください。外部パッケージ、`npm install`、ビルド、APIキーは不要です。

Windowsでは **`play.cmd` をダブルクリック**するとブラウザーが開きます。起動したウィンドウは遊んでいる間、開いたままにしてください。

```powershell
cd C:\Codex\Cyb2\CyberRogue
npm start
```

[http://127.0.0.1:4186](http://127.0.0.1:4186) をブラウザーで開きます。停止は起動した端末で `Ctrl+C`。HTMLファイルの直接起動ではなく、上記のローカルサーバーを使ってください。

ポートを変える場合（PowerShell）：

```powershell
$env:PORT = '4187'
npm start
```

ローカルサーバーはこのPCの `127.0.0.1` だけで待ち受けます。外部から遊ぶ場合は上記のGitHub Pages公開版を使います。

## 最初の十二夜

1. 「元ソロ」「元ネットランナー」「闇医者のツテ」から前歴を選びます。「街の合言葉」は任意の乱数シードです。空欄なら新しい街で始まります。
2. 地区マップで二夜先までを見て、今夜の行き先を一つ選びます。依頼、闇医者、古物屋、路地裏、隠れ家、事件の使いどころを考えます。
3. 依頼ではルート、現場1〜3名、支援0〜2名、ネット0〜1名を編成します。必須ロール、ニュース、成功の見込みを比較し、必要なら情報を購入します。
4. 「次の通信を受ける」で派遣を進めます。自動進行も選べます。判断待ちになると自動進行が止まり、続行／撤退や鎮圧班への対応を選びます。
5. 成功報酬の候補から一つを取り、義体や装備なら受取人を選びます。どれも不要なら500crを受け取れます。
6. 4・8・12夜の大仕事を越えます。第1幕後に組む企業を選ぶと、後半の物語と最後のボスが変わります。

ソロは交戦、ドライバーは運転・逃走、ネットランナーはネットレーン、テックは電子と装甲対策、メドテックは治療・説得を得意とします。報酬と路地裏で足りない役割を補いましょう。全員を専属にすると手当が増えるため、歩合契約との使い分けも必要です。

## 覚えておくルール

- 判定は **能力＋技能＋補正＋d10≧DV**。出目10は追加のd10を足し、出目1は追加のd10を引きます。HP半分未満では判定−2。
- 各列はネット→現場の順。交戦は最大3ラウンド。担当者は編成内でその判定が最も得意な者になります。
- 最大HPは `11＋BODY×4`。被ダメージから防具を引き、貫通されると防具が摩耗します。HP0では `d10＜BODY＋補正` の死亡セーブを行います。
- 義体は部位ごとに2枠、体表だけ1枠。同系統の上位モデルは置き換えます。取り外しても人間性は返りません。
- 人間性31以上は安定、16〜30は動揺の危険、15以下は発作の危険。暴走は火力を増しますが指示を聞かず、鎮圧班を呼ぶ原因になります。0で隊から離脱します。
- 隠れ家はHP回復と人間性＋5。闇医者のセラピーは600crで一人＋15、その人は次の1夜を休みます。
- 毎夜、隠れ家代200cr、専属手当、加入しているラザロの費用を支払います。所持金が3夜連続でマイナスなら廃業です。
- 大仕事失敗、動ける隊の喪失、廃業でラン終了。大仕事からの撤退は一度だけ再挑戦でき、ボスに与えた損傷は残ります。難易度第5段では再挑戦できません。

ゲーム内の「ルール」で詳細を確認できます。成功の見込みは編成と経路を比較する目安であり、結果の保証ではありません。

## 保存と操作

操作はマウス／タップ、または `Tab` と `Enter`。詳細画面は `Escape` で閉じられます。音は任意で切り替えられます。

保存先はブラウザーの `localStorage` です。

| キー | 保存するもの |
| --- | --- |
| `fixers-cut.rogue.run.v1` | 隊、マップ、資金、乱数状態、派遣途中・判断待ちを含む現在のラン |
| `fixers-cut.rogue.meta.v1` | 信用、解放、慰霊碑、物語の断片、過去のラン、難易度 |
| `fixers-cut.rogue.settings.v1` | 音と通信速度 |

各操作後に自動保存します。タイトルの「続きから再開」で戻れます。ブラウザーの保存データを消すと記録も消えます。別ブラウザー・別プロファイル・別ポートには保存が共有されません。クラウド保存や旧キャンペーン版セーブの移行はありません。

| 内容 | 数 |
| --- | ---: |
| ロール／前歴 | 5／6 |
| 通常依頼 | 18＋信用解放3 |
| 義体 | 44（基本系統31＋新しいビルド用13） |
| 武器／防具／道具 | 13／10／4 |
| 固有ボス | 5（1・2幕共通、3幕は企業別） |
| ニュース／街の事件 | 17／8 |
| 物語つきランナー | 5 |
| 信用による解放 | 10項目、全解放に390信用 |

信用による解放は選べる前歴・内容を増やし、ランナーの能力値を次のランへ持ち越しません。クリアにより、効果を重ねる難易度第1〜5段が開きます。

## 検証

```powershell
npm test
npm run balance
```

`npm test` は企画書の数値、コンテンツ参照、夜進行、撤退再挑戦、保存用シリアライズ、事件・報酬・人間性等を確認するルールテストです。テスト実行の設定と一覧は `package.json` と `tests/spec.test.mjs` を参照してください。

`npm run balance` はプレイヤーと同じエンジンAPIで、初心者・慎重の2方針を各1,000ラン実行します。結果は `test-results/balance.json` に出力されます。

短時間の試行は、PowerShellで `$env:RUNS = '100'` を設定してから実行できます。最終評価には既定の各1,000ランを使ってください。自動ランでの目標は、初心者のクリア率15〜25%、慎重50%以上、差20ポイント以上です。ボットの方針・経路選択は `tests/balance.cjs` で確認できます。

**検証済み**：独立ルールテスト63件、実ブラウザー検証47項目、通常UI操作による12夜クリア・42信用の保存・判断待ちからの再開を確認しています。各1,000ランのクリア率は初心者18.9%、慎重58.3%（39.4ポイント差）。最新コードと照合した結果を [検証記録](docs/verification.md) と `docs/validation/` に保存しています。

1ラン30〜45分は読む時間・判断時間を含む企画上の目安で、人による実測は未実施です。高速自動進行では短くなります。主観的な楽しさを保証する値ではなく、異なる編成・企業・ビルド・結末を試せる構成と、判断方針による上記の差を確認しています。

画面テストを再実行する場合だけPlaywrightとEdgeが必要です（ゲームの起動には不要）。`PLAYWRIGHT_PATH` にPlaywrightの場所を設定し、起動中のサーバーへ `node tests/browser-smoke.cjs`、`node tests/full-run.mjs` を実行します。`BASE_URL` で接続先を変更できます。

## 構成

```text
index.html             起動画面
src/app.js             画面・入力・保存・操作音・SVGビジュアル
src/style.css          画面のスタイル
src/data.js            依頼・装備・義体・人物・ニュース・事件
src/engine.js          状態遷移・判定・交戦・経済・報酬・メタ進行
tools/server.mjs       外部パッケージを使わないローカルサーバー
tests/spec.test.mjs    仕様・回帰テスト
tests/balance.cjs      乱数シードを固定した自動ラン
docs/                  要件と判断の記録
```

背景都市とランナーの画像は画面内のSVGとして新規制作しています。外部画像・フォント・音声の配信サービスに依存しません。
