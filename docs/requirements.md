## 1. ラン・終了条件・夜

- [ ] 3幕×4夜＝12夜。毎夜1つの行き先を選び、各幕4夜目は大仕事。
- [ ] 夜1〜4は屋台街（引き継ぎ／鍵を探す）、5〜8は港湾倉庫（積み荷／沈む名前）、9〜12は企業区画上層（調整役／夜明け）。
- [ ] 廃業、動けるランナー不在、大仕事失敗でラン終了。通常依頼失敗は自動でラン終了にしない。
- [ ] 死んだランナーはそのランでは戻らない。
- [ ] 大仕事撤退は次の夜に1度だけ再挑戦。追加夜を幕の夜数に数えず、耐久の削りを維持、護衛は全復活。難易度5では再挑戦不可。
- [ ] 2夜依頼は2夜を消費し、その分希少報酬を保証。大仕事を飛ばさない夜処理を検証する。
- [ ] ラン終了後は前歴選択から次のランを開始。

## 2. 能力・判定・編成・派遣

- [ ] BODY: 最大HP＝11＋BODY×4、死亡セーブ。REF: 射撃・回避・運転。INT: 知覚・インターフェース。TECH: 電子・医療。COOL: 隠密・説得。EMP: 人間性上限＝EMP×10。
- [ ] 能力＋技能＋補正＋d10≧DV。10で追加、1で減算（既存方式を維持）。
- [ ] HPが最大HPの半分未満で判定−2。鬼火中は無視。
- [ ] 技能n→n＋1に必要な使用／成功回数はn＋1、最低2回。既存のn＋4から短縮。
- [ ] 技能担当は「対応能力＋技能」が最大の適任者。現場3・支援2・ネット1の配置枠。
- [ ] 現場／ネット2レーンを持ち、各列でネット→現場の順で解決。
- [ ] 隠密・罠・扉・交渉・医療・運転・逃走・交戦・休息・目標の各フェーズを実装。
- [ ] 交戦は3ラウンド、原則前から順に攻撃。射撃は敵DV、回避は敵攻撃値に対して判定。
- [ ] 被弾ダメージ−現在防具、貫通すると防具1摩耗。休息で即席修理。
- [ ] HP0で死亡セーブ: d10がBODY＋補正「未満」で生存。負傷・行動不能を正しく処理。
- [ ] 重傷・警報・死亡セーブ生存で続行／撤退判断、1依頼2回まで。暴走時の禁止と整合。
- [ ] 必須ロール・地区・ニュース影響、予想成功率、フェーズ表を派遣前に表示。不足ロールがいても警告つきで受注できる。
- [ ] 同じ顔ぶれの編成を再利用できる。

## 5. 報酬・ビルド誘導

- [ ] 成功報酬crとは別に3択（寄せ集め2択）。失敗／撤退では出さない。不要なら500crでスキップ。
- [ ] 種別重み: 義体25・装備25・ランナー15・情報券15・cr20。
- [ ] 義体は施術費なし、人間性コストあり、適合ロールだけから対象者を選択。
- [ ] 装備は武器・防具・道具、持ち主選択。ランナーは歩合で加入。情報券は情報2回無料。
- [ ] cr報酬: 幕1＝800、幕2＝2,000、幕3＝4,000。
- [ ] 幕1は基本義体・装備700〜2,000相当。幕2はMk.II・装備5,000まで。幕3はMk.III・全装備。
- [ ] 資質の基本率: 異常適合3%・適合体質10%・天才肌8%。幕2は1.5倍、幕3は2倍。
- [ ] 所持義体系統の上位モデル出現重み3倍。不在ロールのランナー重み3倍。
- [ ] 取得済みの同じ品は1ラン1回。提示だけで選ばなかった品は候補へ戻す。
- [ ] 危険依頼・2夜依頼・大仕事の報酬は1つ以上希少保証（上位義体／資質／幕の最高価格装備）。
- [ ] ボス撃破報酬の1つはボス装備・義体（電気屋デッキ、カナメ狙撃義眼等）。

## 7. 人間性・サイバーサイコシス

- [ ] 上限EMP×10（通常40〜80、資質で変動）。義体を入れた後でも治療で元上限まで回復可能。
- [ ] 31以上安定。16〜30不安定: 派遣ごと忠誠−3・歩合要求1.3倍、交戦開始d10＝1でその交戦の射撃／回避−2。
- [ ] 1〜15兆候: 交戦開始に発作。d10≦ceil((16−人間性)/4)。12〜15は10%、8〜11は20%、4〜7は30%、1〜3は40%。

- [ ] 暴走中の撃破ごと企業ヒート＋4確定、テーザーでも回避不可。交戦後人間性−2。暴走ログを別色表示。

- [ ] 隠れ家全員＋5。セラピー1人＋15・600cr・次の1夜派遣不可。

## 16. バランス・完成判定の証拠

- [ ] 初心者bot: 毎夜最高報酬依頼、報酬ランダム、常に続行。慎重bot: 高成功見込み依頼、情報購入、重傷撤退、義体系統を追う報酬。
- [ ] 実ゲームと同じ判定／状態遷移を使う、固定乱数の完全ランを各1,000回。単独チェック成功率だけでクリア率を代用しない。
- [ ] 初心者クリア率目標約20%、幕通過目安80%→55%→45%（条件付き）。慎重50%以上、両者差20ポイント以上。
- [ ] 幕ごとの脱落、死亡、廃業、人間性喪失、資金、報酬／ビルド分布を記録して調整。
- [ ] 確率見込みが実際の派遣ロジックを反映する。役割・情報・義体・装備・人間性・ニュース・敵特性を考慮。
- [ ] 序盤2人で通常依頼成功70〜90%、3人ならほぼ確実、幕2大仕事／危険依頼は60%前後という目安を評価。
- [ ] 加速ソロ／鉄腕／影／現場ハッカー／鬼火の5ビルドが実際に違う長短を示す。
- [ ] 生成制約・戦闘固有効果・救急／鎮圧・夜遷移／再挑戦・報酬重複・保存復帰・解放／難易度を意味ある自動検証でカバー。
- [ ] ブラウザーで開始→編成→派遣→報酬→店／休養→大仕事→企業選択→全幕→結果→メタ→次ランを通して操作し、表示・操作性・通信・保存復帰を確認。
